# DNA Methylation Data Analysis

A bioinformatics pipeline for whole-genome bisulfite sequencing (WGBS) data analysis, covering raw read quality control, differentially methylated region (DMR) detection, genome browser track generation, and visualisation of methylation signals.

---

## Overview

Whole-genome bisulfite sequencing is the gold standard method for measuring DNA methylation at single-base resolution across the entire genome. Bisulfite treatment converts unmethylated cytosines to uracil while leaving methylated cytosines unchanged, allowing methylation status to be inferred from the resulting sequence reads after alignment to a reference genome.

This repository collects the outputs and scripts from each stage of a WGBS analysis pipeline, organised by tool. The workflow moves from raw data quality assessment through methylation-level quantification, statistical identification of differentially methylated regions, and finally the generation of files suitable for visual inspection in a genome browser.

## Pipeline Stages

### 1. Quality Control — Falco

The `falco/` directory contains HTML quality control reports generated by [Falco](https://github.com/smithlabcode/falco), a high-speed emulation of the widely used FastQC tool. Falco runs approximately three times faster than FastQC while producing equivalent results, making it well suited for large WGBS datasets.

Each report covers the following metrics per sample:

- Per-base sequence quality scores across read positions
- Per-sequence quality score distributions
- Per-base nucleotide composition (used to assess bisulfite conversion in WGBS, where T enrichment at non-CpG positions indicates successful conversion)
- GC content distribution
- Sequence duplication levels
- Adapter content detection
- Overrepresented sequences

Inspecting these reports before downstream analysis is essential: low-quality tails, poor bisulfite conversion efficiency, or high adapter contamination can all distort methylation calls if not addressed at the trimming stage.

### 2. Differentially Methylated Regions — Metilene

The `metilene/` directory contains the output of [metilene](https://www.bioinf.uni-leipzig.de/Software/metilene/) (Jühling et al., 2016, *Genome Research*), a tool for fast and sensitive identification of differentially methylated regions between two groups of samples from bisulfite sequencing data.

Metilene uses a binary segmentation algorithm combined with a two-dimensional statistical test (a combination of a Mann-Whitney U test and a 2D Kolmogorov-Smirnov test) to detect genomic segments that differ in methylation level between conditions. This approach makes it particularly effective at low sequencing coverage and it can handle missing data across samples. It outperforms alternatives such as BSmooth and MOABS in sensitivity across a range of coverage depths.

The output files typically include:

- Genomic coordinates of each DMR (chromosome, start, end)
- Mean methylation level in each group
- Magnitude of methylation difference
- Adjusted p-values
- Number of CpG sites within the DMR

These results can be used to prioritise regions for functional follow-up, annotate DMRs against gene bodies and promoters, or perform gene ontology enrichment analysis on nearby genes.

### 3. Genome Browser Tracks — BigWig

The `bigwig/` directory contains genome-wide methylation signal files in [BigWig format](https://genome.ucsc.edu/goldenpath/help/bigWig.html). BigWig is a compressed, indexed binary format that encodes continuous numerical values (here, per-base or per-CpG methylation rates) mapped to genomic coordinates.

These files can be loaded directly into genome browsers such as:

- [IGV (Integrative Genomics Viewer)](https://igv.org/)
- [UCSC Genome Browser](https://genome.ucsc.edu/)
- [JBrowse](https://jbrowse.org/)

BigWig tracks allow visual inspection of methylation levels across any genomic region of interest, comparison between conditions or samples, and cross-referencing against gene annotations, repeat elements, or other epigenomic marks such as histone modifications.

### 4. Visualisation — Plots

The `plot/` directory contains figures produced from the processed methylation data. These may include methylation level distributions across genomic features (CpG islands, shores, shelves, gene bodies, promoters), coverage histograms, DMR methylation profiles, and any comparative plots between sample groups.

## Background: The WGBS Analysis Workflow

A typical WGBS analysis pipeline, of which this repository represents the downstream stages, proceeds as follows:

1. **Raw read QC** — assess read quality, adapter content, and bisulfite conversion rate (Falco / FastQC).
2. **Adapter trimming** — remove adapter sequences and low-quality bases (Trim Galore, Trimmomatic).
3. **Alignment** — map bisulfite-converted reads to a reference genome using a bisulfite-aware aligner (Bismark, bwa-meth, BSMAP).
4. **Methylation extraction** — call methylation status at each CpG site from aligned reads.
5. **Format conversion** — generate bedGraph and BigWig files from per-CpG methylation tables.
6. **DMR detection** — identify genomic regions with statistically significant methylation differences between groups (metilene).
7. **Visualisation and annotation** — plot methylation profiles and annotate DMRs against genomic features.

This repository contains the outputs of steps 1, 5, 6, and 7.
